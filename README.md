# 霓虹轮廓描边工具

一个纯前端、开源的图片霓虹描边工具。

## 功能
- 上传本地图片（JPG / PNG / WebP）
- 鼠标拖动框选目标区域（支持触屏）
- 两种描边模式：
  - **沿轮廓描边**：在选区内自动检测物体边缘（Sobel 算法），沿真实轮廓添加霓虹发光线条
  - **矩形描边**：沿框选区域画霓虹矩形
- 可调霓虹颜色、线条粗细、光晕强度、轮廓敏感度
- 一键下载处理后的图片

## 使用
图片完全在本地浏览器处理，不会上传到任何服务器。

1. 打开 `index.html`
2. 上传图片
3. 拖动框选要描边的物体
4. 点击「生成霓虹」
5. 下载图片

## 部署
本项目通过 GitHub Pages 部署：https://<你的用户名>.github.io/<仓库名>/

## 技术说明
- 纯原生 HTML / CSS / JavaScript，无任何依赖
- Canvas 2D 绘制，Sobel 边缘检测提取物体轮廓
- 霓虹发光效果通过 `shadowBlur` 多层光晕叠加实现
